# Fixed-direction flux/reconstruction audit (2026-11-04)

This follows stagnationDiagnostics. The large mismatch is not solely a
high-order reconstruction effect: it remains with piecewise-constant AUSM
states and decreases substantially when the residual flux is changed to LF.
These are derivative diagnostics, not convergence demonstrations or production
scheme recommendations. No default discretization or solver was changed.

## Controls

All probes use exactly the same saved L3 state (3024 cells), CFL 5, GMRES
subspace 40, LUSGS, and the same conservative update deltaW generated by the
original high-order AUSM/centralLaxFriedrichs solve. Turbulence is frozen during
each residual probe. There is one outer iteration per case. Differencing
steps h=1e-3 and 5e-4 mean W0 +/- h*deltaW.

The reference case writes auditDeltaRho, auditDeltaE and auditDeltaMom in
constant (gzip when requested by controlDict). Other cases read exactly these
fields using `directionAuditUseStored true` in flowSolver/GMRES. Only the
probe direction is replaced: the underlying computed flow update is restored
and applied normally. Use a single iteration when generating the reference,
since each diagnostic iteration overwrites its exported direction.

An explicit `firstOrder` reconstruction was registered using the existing
limited-reconstruction framework with a zero limiter. Existing interpolation
weights then become 1 on the left and 0 on the right, giving owner/neighbour
values on internal faces. Existing physical-boundary handling is retained.
For AUSM, apply it to reconstruct(rho), reconstruct(U), reconstruct(T).
This tests reconstruction while retaining the AUSM flux formula. LF's native
flux does not use these reconstruction entries.

Both native and ADR HiSA builds passed in
`dafoam_case/validation/hisa_direction_build`. No installed libraries or shared
SA model were modified. This is a native diagnostic; compilation of the ADR
variant does not establish gradient accuracy.

## Results

Each error is ||Japprox*deltaW - Jtrue*deltaW|| / ||Jtrue*deltaW||. The total
uses frozen density/momentum/energy scales; each block uses its own true
block derivative norm. They are not residual reduction factors.

| Residual flux/reconstruction | Approximate Jacobian | Total error | Density | Momentum | Energy |
|---|---|---:|---:|---:|---:|
| AUSMPlusUp, wVanLeer | centralLaxFriedrichs | 4.69282 | 3.35465 | 7.07828 | 3.30396 |
| AUSMPlusUp, firstOrder | centralLaxFriedrichs | 3.28172 | 2.76783 | 3.80231 | 2.69866 |
| LaxFriedrichs | centralLaxFriedrichs | 0.66842 | 2.17612 | 0.11982 | 1.67807 |
| LaxFriedrichs | LaxFriedrichs | 0.65549 | 2.16743 | 0.02815 | 1.66495 |

Halving h preserves every reported derivative norm/error within 1e-6 relative.
All zero-step residual consistency checks pass below 1e-8. Direction files
match by decompressed SHA256 across cases, and all initial state arrays match.
Reading the exported direction back into the high-order reference calculation
produces exactly the same final state and residual as generating it in memory.

The errors are direction-specific, not matrix norm estimates. Switching flux
also changes its base residual and derivative norm; the fixed direction
removes the previous update-direction confound but does not make these
residual equations equivalent. Do not interpret the table as an additive
percentage attribution of the error or compare total residual reductions
across discretizations as a convergence benefit.

Reconstruction accounts for some of the mismatch, but turning it off does not
resolve it. The LF approximate operator models the LF residual much better
along this direction than it models AUSM. Yet even the matching LF case is
not an exact Jacobian. Its remaining mass/energy errors merit investigation
of frozen dissipation/wave-speed and boundary linearizations; no specific
missing term has been established by this experiment. A density-block
mismatch means viscous terms alone cannot explain the problem.

The next targeted question is which convective flux derivatives should be
represented in the update operator at acceptable cost. The current evidence
does not require replacing LUSGS, enlarging GMRES, or changing the shared SA
model. It also does not prove that full matrix-free NK is cost-effective.

## Reproduction

Activate the workspace OpenFOAM/DAFoam environment, prepend the diagnostic
DAFoam and HiSA library directories to LD_LIBRARY_PATH, and use one BLAS/OMP
thread. Wait until both library builds finish before starting tests.

Common cfl_sweep.py arguments, from the workspace root:

```
--source dafoam_case/validation/dafoam_L3_central_continue/cfl5_0
--source-time 1000 --hisa-repo Hisa4DAFoam
--hisa-lib dafoam_case/validation/hisa_direction_build/lib
--jacobian centralLaxFriedrichs --direction-audit --steps 1 --cfl 5
```

Generate `dafoam_L3_fixed_direction_reference` under dafoam_case/validation
without overrides. Then use fresh outputs with prefix
`dafoam_L3_fixed_direction_v2_`, adding
`--direction-reference dafoam_case/validation/dafoam_L3_fixed_direction_reference/cfl5_0/constant`:

- ausm_high: --flux-scheme AUSMPlusUp --reconstruction wVanLeer
- ausm_first: --flux-scheme AUSMPlusUp --reconstruction firstOrder
- lf_central: --flux-scheme LaxFriedrichs --reconstruction firstOrder
- lf_geometric: same LF settings, --jacobian LaxFriedrichs

Audit:

```
python dafoam/tests/hisaConnectivity/summarize_flux_direction.py \
  --root dafoam_case/validation \
  --output dafoam/tests/hisaConnectivity/fluxDirection
```

Full reports, hashes and checks are in results.json; logs and direction fields
remain in the workspace. Earlier exploratory LF runs using their own update
directions gave errors 0.094/0.087, which are NOT the fixed-direction results.
An AUSM trial with unsupported `upwind` reconstruction exited before solving;
the initial stored-direction copies also failed because the files were gzip.
Those failed trials are excluded. The driver now supports compressed direction
files and only advertises valid reconstruction choices.
